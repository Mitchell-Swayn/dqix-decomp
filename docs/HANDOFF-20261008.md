## Reconstruction lessons

- Ordinary typed C/C++ tail callers can match ARM veneers with `ARM` and `#pragma optimization_level 4`. Use actual reviewed header contracts and exact mangled symbols; never code-address function pointers to imitate veneers.
- Comparison summary `differences` is truncated to ten rows. Select accepted subsets from the artifact directory's **complete `units.json`**, not the summary.
- Object matching alone is insufficient. A delink split can garbage-collect an unused following fallback and shift linked addresses. `#pragma force_active on` can help legitimate source retention, but placement can also retain unwanted generated C++ assignment functions. Always verify linked layout and the full ROM.
- The second-run coordinator synchronized already accepted `func_020dbff4` into its independent workspace to resolve a neighboring layout issue. It was credited only to B's original receipt. Two earlier layout deferrals were later independently reverified and accepted under `co_revival`.
- Load byte signedness and bitfield widths matter. `func_02001a40` is the actual `memcpy` symbol: invented unmangled aliases can fail exact relocation matching even when instructions look close.
- Match globals against exact relocation records in `config/usa/arm9/relocs.txt`; never infer declarations from literal-pool addresses alone.
- Fetch context incrementally, compile promptly, accept verified subsets from small groups, and move on after at most ten unproductive variants.
- Initially defer `_ffix` 0200c5fc, `_fflt` 0200c670, `_ffltu` 0200c6b8, `_fmul` 0200c7d4, VectorizedMemset 020ca594, VectorizedInvertedMemcpy 020ca650, and costly CLZ/computed-jump/runtime helpers. Prior `_ffix` syntax guessing already failed 110 variants.
- No assembly wrappers, binary substitutes or denominator reductions. Necessary assembly needs established provenance, separate review and separate accounting.
