How coverage is counted

ARM9 measures reconcile with the complete input report. Data includes BSS. Purple identifies accepted runtime assembly helpers; other treemap colors represent owning-unit coverage; function tiles subdivide units by symbol size. Filtering the table does not reduce the coverage denominator.

The source audit conservatively flags whole units containing assembly syntax, including local headers. It does not measure exact assembly instruction bytes or establish that all other units are pure C/C++.

ARM7 separates C instructions, literals, initialized data, reviewed assembly, runtime BSS and original fallback. Its fallback may contain both code and data. A matching ROM alone does not establish complete decompilation or gameplay correctness.
